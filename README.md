# Refleksionsspørgsmål 
### Hvordan kunne man forhindre at data bliver væk ved crash? 

 Det formår vi ved at gemme til fil alternativt kunne man gemme data i en database.

### Hvad ville du gøre anderledes med en database? 

Der ville vi udskifte vores filhåndtering i vores service/business-logik lag, med kald og metoder til en database. Dette kunne f.eks. være en MongoDB.
